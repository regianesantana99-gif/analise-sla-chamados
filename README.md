# analise-sla-chamados
Projeto de analise e acompanhamento de SLA chamados para suporte. 

## Objetivo

Desenvolver uma ferramenta para acompanhamento do cumprimento de SLA de chamados de suporte, utilizando dados estruturados e indicadores para facilitar a visualização dos resultados.

## Ferramentas utilizadas

- Microsoft Excel ; Fórmulas ; Tabelas ; Gráficos ; Análise de dados ; Indicadores de SLA

## Principais análises

- Total de chamados
- Chamados dentro do SLA
- Chamados fora do SLA
- Percentual de cumprimento do SLA
- Tempo total de atendimento
- Comparação entre chamados dentro e fora do prazo

## Dashboard

O projeto possui um dashboard para visualização dos principais indicadores e do cumprimento do SLA dentro dos prazos pré estabelecidos.

## Contexto

Este projeto foi desenvolvido como parte do processo de transição para a área de Tecnologia da Informação, com o objetivo de aplicar conhecimentos adquiridos durante a formação em Sistemas de Informação e nos estudos de Excel e análise de dados.

A experiência anterior com atendimento e resolução de problemas serviu como referência para a construção do cenário de chamados. Minha experiência profissional envolvia o acompanhamento de chamados relacionados a problemas de rede, especificamente em redes móveis, desde a identificação da ocorrência até o acompanhamento da resolução.

## Observação

Este é um projeto autoral desenvolvido para fins de estudo e portfólio. Não representa uma ferramenta utilizada em ambiente profissional.
